# Documentation

This directory contains the architectural decisions, development guides,
agent instructions, and task records for the Minesweeper project. Code is not
the only source of truth: decisions and repository conventions must be
documented explicitly.

## Sections

- [Architecture](./architecture/README.md): system structure, state model,
  package ownership, and dependency boundaries.
- [Decisions](./decisions/README.md): accepted Architecture Decision Records.
- [Development](./development/README.md): local setup, configuration layout,
  testing, and feature workflow.
- [Agent instructions](./agent/README.md): required workflow and quality rules
  for AI-assisted development.
- [Tasks](./tasks/README.md): planned and completed work with acceptance
  criteria and validation evidence.

## Suggested reading order

1. [Architecture overview](./architecture/OVERVIEW.md)
2. [Package boundaries](./architecture/PACKAGE_BOUNDARIES.md)
3. [Getting started](./development/GETTING_STARTED.md)
4. [Repository configuration](./development/CONFIGURATION.md)
5. The task record relevant to the change
